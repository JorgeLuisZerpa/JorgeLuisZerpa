## 🚀 Projeto em destaque: GoCumaná

Plataforma de tecnologia e logística desenvolvida pela NEXO Technologies, destinada ao mercado venezuelano, com lançamento inicial planejado para Cumaná, no estado de Sucre, Venezuela.

O projeto tem como objetivo conectar clientes, estabelecimentos comerciais e entregadores por meio de aplicativos e serviços digitais, com funcionalidades de geolocalização, gestão de pedidos, autenticação, distribuição inteligente de entregas e integração de APIs.

Atuo no desenvolvimento da arquitetura backend e mobile, modelagem de dados, implementação de regras de negócio e testes automatizados.

**Tecnologias:** TypeScript, JavaScript, NestJS, React Native, Expo, PostgreSQL, Prisma ORM e APIs REST.
